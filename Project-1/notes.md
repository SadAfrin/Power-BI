## What is Power BI?

- Microsoft's **#1 Business Intelligence tool**.
- Data from different sources (Word, Excel, Website, etc.) can be imported into Power BI.
- Power BI is used to perform **data visualization** on that imported data.
- Can be installed directly from the **Microsoft Store**.

---

## How Power BI Works

1. **Blank Report** – This is Power BI's main interface/workspace.
2. **Home tab → Get Data** – Click this to import data from various sources.
3. **Load** – Clicking this loads the data directly into Power BI.
   **Transform Data** – Clicking this opens **Power Query**, where the data can be edited/cleaned before loading.
4. Once data editing is done, click **Close & Apply** – the original files/tables appear as separate tabs (e.g. `Orders`, `Customer Name`).

---

## Views in Power BI

### 1. Report View
The main canvas where visuals/charts are built and the dashboard is designed.

### 2. Table View
Shows the raw data exactly like a normal `.xlsx` file — a plain table format.

### 3. Model View
Shows how different datasets/tables are **linked (related)** to each other, if a relationship exists between them (e.g. `Orders` linked to `Customer Name` via Customer ID).

---

## Formatting a Chart / Visual

To change the design or format of any chart:

1. **Select the chart** → go to **Visual** pane → **General** → **Properties**
   *(This is where most formatting options live in the interface.)*
2. **Theme change** – Changing the theme applies new colors/styles across the **entire report view**, not just one chart.
